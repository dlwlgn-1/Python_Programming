# AI 프로젝트 보고서 초안

## 1. 기본 정보

- 프로젝트명 : 마음날씨 AI 일기장
- 학번 / 이름 : 1323 / 이지후

## 2. 프로그램 개요

### ① 프로그램 소개
일기를 쓰면 AI가 일기의 감정을 기쁨, 슬픔, 분노, 불안 중 하나로 분류하고 그 감정을 날씨(맑음, 비, 천둥번개, 안개)로 보여주는 일기장 프로그램입니다. 쓴 일기는 DB에 저장되고 나중에 다시 보거나 수정, 삭제할 수 있습니다. 학생들이 사용하는 것을 생각하고 만들었습니다.

### ② 주제 선정 동기
시험이나 기숙사 생활 때문에 요즘 내 기분이 어떤지 잘 모르고 지나갈 때가 많았습니다. 수업 때 급식 리뷰를 긍정/부정으로 분류해 봤는데, 이걸 감정 4가지로 늘려서 일기에 쓰면 내 기분을 기록하고 돌아볼 수 있을 것 같아서 이 주제를 정했습니다. 감정을 그냥 글자로 보여주는 것보다 날씨로 보여주면 더 재밌을 것 같아서 마음 날씨라는 이름을 붙였습니다.

### ③ 프로그램 기능
- 일기를 쓰면 AI가 감정을 분류하고 감정별 확률을 그래프로 보여줌
- 감정에 맞는 날씨와 응원 메시지 보여주기
- 일기 DB 저장
- 감정별로 일기 검색
- 일기 수정 (수정하면 감정을 다시 분석함)
- 일기 삭제
- 마음 통계 (전체 일기 수, 가장 많은 감정, 감정별 개수 그래프, 최근 마음 날씨)

## 3. 화면 설계

- ① 화면명 : 마음날씨 AI 일기장 (메인 화면)
- ② 화면 설명 : 한 화면에서 일기 쓰기, 일기장, 마음 통계를 차례로 볼 수 있습니다. 일기를 쓰고 저장하면 AI 분석 결과가 나오고, 일기장 표에서 일기를 고르면 수정하거나 삭제할 수 있습니다.
- ③ 화면 구성 (캡처 넣기)
  - 1. 일기 쓰기 : 날짜 선택, 일기 입력창, 저장 버튼, 분석 결과(마음 날씨, 확률, 응원 메시지, 확률 그래프)
  - 2. 일기장 : 감정 선택(전체/기쁨/슬픔/분노/불안), 일기 목록 표, 선택한 일기 수정창, 수정하기/삭제하기 버튼
  - 3. 마음 통계 : 전체 일기 수, 가장 많은 마음 날씨, 감정별 일기 수 그래프, 최근 마음 날씨

## 4. 모듈 설계

| 번호 | 모듈명 | 모듈 설명 |
|---|---|---|
| 1 | Web 모듈 (app.py) | 사용자 입력을 받고 화면에 일기, 분석 결과, 통계를 표시합니다. |
| 2 | AI 연동 모듈 (mood_ai.py) | 학습한 모델로 일기 감정을 분류하고 감정별 날씨, 메시지를 정합니다. |
| 3 | DB 데이터 관리 모듈 (diary_db.py) | 일기의 저장, 조회, 수정, 삭제를 담당합니다. |
| 4 | 모델 학습 (train.py) | 감정 데이터로 모델을 파인 튜닝하고 저장합니다. |

## 5. 구현

### ① AI 모델 활용 ☑
- AI 모델 : "monologg/koelectra-small-v3-discriminator" (파인 튜닝)
- 입력 데이터 : 한국어 일기 문장 200개 (기쁨, 슬픔, 분노, 불안 각 50개 / 학습용 160개, 평가용 40개)
- 출력 데이터 : 기쁨(0), 슬픔(1), 분노(2), 불안(3)
- 학습 결과 : 평가용 정확도 25% → 90% (60번 학습)

### ② WEB ☑
Streamlit으로 만들었습니다. 일기를 입력하고 저장 버튼을 누르면 AI가 감정을 분류하고 DB에 저장한 다음 결과를 보여줍니다. 일기장 표에서 행을 선택하면 수정창과 수정/삭제 버튼이 나옵니다. 마음 통계는 DB에서 일기를 불러와 감정별 개수를 세서 그래프로 보여줍니다.

### ③ DB ☑
- 테이블명 : diaries
- 컬럼명 : id(번호), diary_date(날짜), content(내용), emotion(감정), score(확률), created_at(작성시각)

## 6. 테스트

| 번호 | 테스트케이스명 | 입력조건 | 실행결과 |
|---|---|---|---|
| 1 | 일기 저장 | "내일 동아리 면접인데 떨어질까 봐 너무 걱정돼서 잠이 안 온다" 입력 후 저장 | 마음 날씨 안개, 불안 76%, 응원 메시지와 그래프 나옴 |
| 2 | 빈 일기 저장 | 아무것도 입력 안 하고 저장 | "일기 내용을 입력해 주세요." 경고 나옴 |
| 3 | 감정 검색 | 일기장에서 분노 선택 | 분노 일기 1개만 나옴 |
| 4 | 일기 수정 | 분노 일기를 "조별 과제를 친구들이랑 다 같이 끝내서 너무 뿌듯하고 기뻤다"로 수정 | 천둥번개 → 맑음(기쁨 0.74)으로 바뀜 |
| 5 | 일기 삭제 | 7번 일기 선택 후 삭제 | 목록에서 사라지고 전체 일기 7개 → 6개 |

## 7. 느낀 점

- 처음에 30번만 학습했을 때는 정확도는 괜찮았는데 확률이 40% 정도로 낮게 나와서, 60번으로 늘렸더니 확률이 70%대로 올라갔습니다.
- 한 일기에 여러 감정이 섞여 있어도 하나만 고르는 점이 아쉬웠습니다. 데이터를 더 많이 만들면 더 정확해질 것 같습니다.
